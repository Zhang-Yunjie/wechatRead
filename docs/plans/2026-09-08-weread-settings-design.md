# 微信读书 API 设置设计

## 目标

用户可在“设置与数据”页面直接配置微信读书 API Key，保存后立即用于手动同步，不需要编辑 `.env.local` 或重启本地服务。

## 交互

- 微信读书卡片提供密码输入框，以及“保存配置”“测试连接”“清除配置”。
- 页面不回显完整 Key，仅展示是否已配置和末尾四位掩码。
- 保存、验证和清除均显示明确的成功或失败反馈。
- “测试连接”只调用微信读书只读能力，不触发本地书架同步。

## 存储与优先级

- 页面保存的 Key 写入 `data/secrets.json`，该目录已被 Git 忽略。
- 文件通过临时文件加原子替换写入，并设置为仅当前用户可读写（`0600`）。
- 密钥不进入 SQLite，不出现在后端响应或日志中。
- 页面配置优先于 `WEREAD_API_KEY` 环境变量；清除页面配置后自动回退到环境变量。
- `WEREAD_SKILL_VERSION` 继续使用环境变量，未配置时使用默认版本 `1.0.4`。

## 数据流

1. 设置页只读取安全状态摘要：配置来源、掩码和连接状态。
2. 保存接口验证输入非空，然后写入本地密钥文件。
3. 微信读书客户端在每次请求前动态读取页面配置，缺失时回退到环境变量。
4. 测试连接接口使用同一客户端调用只读书架接口，并只返回成功或经过清理的错误信息。
5. 清除接口只删除页面保存的微信读书 Key，不影响 AI 配置或阅读数据库。

## 错误处理

- 无效输入返回 400；未配置时测试连接返回 400；微信读书拒绝授权或网络失败返回可理解的错误。
- 文件读取损坏时不暴露文件内容，按未配置处理；写入失败返回 500。
- 所有响应禁止包含完整 API Key。

## 验证

- 单元测试覆盖本地文件保存、权限、掩码、清除和环境变量回退。
- API 测试覆盖保存、查询状态、验证连接和错误脱敏。
- 组件测试覆盖表单提交、掩码状态及清除交互。
- 完成后执行全量测试、lint、TypeScript、生产构建，并在本地浏览器实际保存与清除一枚测试 Key。
